# Lab-10
In this lab I learned how to program the ESP32 to react to events using polling, interrupts and millis() timers. I built a small touch alarm where button A arms and disarms it, touching a wire triggers it, and button B silences it, using callbacks to connect each event to its action.
# Required Equipment
- ESP32 Development Board (Espressif ESP32-DevKitC)
-	2 × push buttons
-	1 × male-to-male jumper wire (used as the touch sensor)
-	Green LED and Red LED
-	2 × 220 Ω resistors
-	Active piezo buzzer
-	Breadboard
-	Jumper Wires
-	USB Cable
# Software
-	Visual Studio Code
-	PlatformIO
-	Serial Monitor
-	lab10_starter_main.cpp file (provided by my instructor)
